# 口袋守卫

微信小游戏原生 Canvas 2D 原型，无服务端和第三方依赖。

源代码采用 MIT 许可证，详见 LICENSE。当前所有代码和占位图形均随项目提供；微信运行环境由平台提供，不属于本项目开源范围。目前源码仅保存在本地，尚未发布到公开代码仓库。

## 导入

1. 微信开发者工具首页选择导入项目，目录选择 `Y:\小程序游戏\第一款`。
2. 使用自己的小游戏 AppID；尚无账号时，可尝试工具提供的游客/测试入口（入口和可用能力以当前工具为准）。项目内 `touristappid` 仅用于本地尝试，不能用于正式上传发布。
3. 项目类型应为小游戏，选择不使用云服务。若导入窗口无类型选项，导入后确认识别为小游戏。
4. 编译运行。正式 AppID 和开发者权限就绪后，使用预览二维码在手机测试。

## 操作

启动后先进入主页面，点击“进入关卡”打开地图选择。完成前一关会自动解锁下一张地图，进度保存在本机。进入关卡后，点击底部塔种，再点击道路之间带加号的空地建造。每张地图都有独立的折返路线，逐关增加波数、敌人生命、移动速度和出怪密度。道路禁止建造。初始 150 金币；开始波次后自动攻击。每波完成获得补给，并选择一项升级。完成当前地图的全部波次获胜，基地生命归零失败。

- 速射塔：短间隔追踪弹，优先攻击沿道路行进最远的敌人，适合单体输出。
- 爆破塔：较长射程、较慢抛射，0.65 秒后在发射时锁定的落点爆炸，对 52 范围内敌人造成伤害；快速敌人可能逃出落点。
- 冰霜塔：不发射单体弹，向自身周围释放范围脉冲，轻微伤害并减速两秒，适合配合爆破塔。

战场格子高度最多 90 个逻辑像素，保证长屏设备上冰霜塔也能覆盖相邻道路；攻击射程不会随屏幕高度改变。

点击已部署的守卫打开管理面板，查看当前伤害、射程和攻击间隔，并显示攻击范围。金币升级最高三级：枪手强化伤害和攻速，炮手强化伤害和爆炸范围，冰法师强化减速程度和持续时间；二级增加金色护肩，三级增加披风和胸前宝石。出售返还建造及升级累计投入的 70%（向下取整）。面板右上角可关闭，战斗期间管理面板不会暂停游戏。受击有闪白和浮动伤害数字，击杀有消散粒子。

黄色敌人速度较快，紫色敌人生命较高且突破后扣两点生命。战斗期间可继续建造。最高完成波次保存在本机；本版本不保存进行中的对局。

## 当前范围

三种塔、三种敌人、十个波次、五种局内升级、本地最佳成绩、前后台暂停。当前美术为占位图形；不包含广告、支付、登录、排行榜、云存档或发布资质准备。

核心逻辑在 `src/game.js`，微信入口在 `game.js`。需在微信开发者工具及手机中进一步确认画面、触控和性能。

## 修改与规范

- `src/config.js`：塔的价格、伤害、射程、攻击间隔、颜色及升级效果。
- `src/path.js`：道路格子、路点生成、移动距离和转弯处理；改地图时优先修改 `ROAD_CELLS`，保持相邻格子连通。
- `src/game.js`：状态转换、建造、战斗与触控逻辑。
- `src/renderer.js`：卡通草地战场、防御塔、怪物、按钮与弹窗绘制；`PALETTE` 为主要配色。图形全部使用 Canvas 路径实现，随 MIT 源码提供，无外部素材。
- `src/characters.js`：原创 Q 版枪手、炮手、冰法师，以及史莱姆、疾跑小兽、重甲独角怪；包含服装、武器、待机动作和冰冻外观。`GUARDIANS` 为角色服装配色，造型使用局部坐标绘制。
- `src/animation.js`：实际攻击事件驱动的姿态计算与职业动画时长；枪手后坐抬枪、炮手下蹲开炮、法师挥杖，包含枪口闪光、烟雾与冰晶粒子。动画与攻击冷却独立，不改变伤害结算时间。
- `src/tower-stats.js`：三级职业成长、升级费用与出售比例；面板显示和战斗结算共享属性计算。
- `src/levels.js`：四张地图的路径、波数和难度参数；`GRID` 统一控制 7 列 × 9 行的窄格子布局、道路宽度和角色缩放。
- `game.js`：微信 Canvas、屏幕缩放、生命周期与本地存储适配。
- `tests/game.test.js`：建造约束、升级、胜负状态的自动验证。
- `.editorconfig`：UTF-8、两空格缩进和 LF 换行。

有 Node.js 时运行 `npm run check` 和 `npm test`，无需安装依赖。逻辑验证不替代微信模拟器和真机测试。新增功能应保持平台 API 在入口适配层，调整游戏数值优先修改配置，公共源码中不要提交密钥或私人配置。新增第三方素材或代码前需确认许可证并保留来源说明。
